Especificação Técnica

Arquitetura do Sistema

A estrutura de desenvolvimento que fundamenta o TCC do Curso Técnico de Informática.

code Frontend & PWA

  • ✅ HTML5 Semântico & CSS Variables: Interface fluida, responsiva e suporte nativo a Dark Mode.
  • ✅ JavaScript ES6+: Manipulação assíncrona da DOM e consumo de APIs via Fetch/Axios.
  • ✅ Progressive Web App (PWA): Funciona como aplicativo nativo no smartphone sem instalação pela loja.

storage Backend & API de IA

  • ✅ Node.js / Python REST API: Gerenciamento de rotas, autenticação e regras de negócio.
  • ✅ Integração com LLM (Gemini API): Processamento de Linguagem Natural com engenharia de prompts pedagógicos.
  • ✅ Banco de Dados Relacional/NoSQL: Armazenamento de turmas, progresso do aluno e métricas do Pomodoro.

Sobre o Trabalho de Conclusão de Curso

O EduSmart AI foi idealizado como uma proposta de intervenção tecnológica pedagógica para o Ensino Médio, demonstrando como a união entre os dispositivos móveis e a Inteligência Artificial pode potencializar a rotina de estudos e auxiliar professores no acompanhamento do aprendizado.
